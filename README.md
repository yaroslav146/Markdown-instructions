> **This repository is not an official GitHub project.**

## ℹ️ About

This repository contains a simplified overview of commonly used **Markdown** and **GitHub Flavored Markdown (GFM)** syntax.

The examples are intended to make Markdown syntax easier to understand and remember without having to go through the full official documentation every time.

## 📚 Contents

The guide currently covers:

- Headings
- Text formatting
- Code blocks
- Syntax highlighting
- Lists
- Task lists
- Links
- Images
- GitHub mentions
- Footnotes
- Notifications
- Comments
